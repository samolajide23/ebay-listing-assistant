# Store listing draft

## Name

OlaHub eBay Listing Assistant

## Short description

Update shoe sizes and matching title sizes on eBay listing forms.

## Detailed description

OlaHub eBay Listing Assistant helps sellers update men's shoe-size values on eBay listing forms. Choose a size from M4 to M11, select which fields to update, and apply the changes to the open form. On eBay's Sell Similar listing page, the assistant panel opens automatically and stays available while you edit.

The extension operates on the current eBay page. It does not submit or publish the listing, and it does not send listing contents to a developer server. Always review the form and save it using eBay's own controls.

## Privacy disclosure draft

This extension does not collect, sell, or transfer personal information or browsing activity to the developer. It reads and modifies matching title and shoe-size fields on supported eBay listing pages only to perform the action requested by the user. It does not submit listings.
